# UniMatch — University Recommendation Platform

## Project Overview

**UniMatch** is a university discovery and recommendation website designed to help students explore universities in Karachi in one organized platform.

The website provides students with an easy way to explore different university options based on their academic interests, preferred degree field, budget, university type, and location.

## Project Goal

The main goal of UniMatch is to make university research easier by bringing information about different Karachi universities into a simple, clean, and student-friendly website.

### Tagline

> Your Future. Your Budget. Your University.

## Features

- Karachi-focused university directory
- University preference form
- Individual university cards
- Individual university logos
- University sector/type labels
- Academic field categories
- University location information
- Official university website links
- Responsive design
- Mobile-friendly layout
- Smooth section navigation
- Consistent university card alignment
- Professional academic-inspired design
